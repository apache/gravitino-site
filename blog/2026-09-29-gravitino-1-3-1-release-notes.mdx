We are glad to announce the release of Apache Gravitino 1.3.1! This is a patch release that focuses on stability, correctness, and security hardening. It carries a large number of fixes across the core server, authorization, Iceberg REST, the Trino, Spark and Flink connectors, and the ClickHouse, Doris, Glue, Hive, JDBC and Lance catalogs. It also completes tag support for views and functions across the Java and Python clients, adds view APIs to the Python client, and introduces extension SPIs that let downstream projects plug in their own catalog adapters.

## Improvements

### Core & Server

  - **Locking**: Lock the entity node instead of the schema when creating tables, topics, views and models. [#13206](https://github.com/apache/gravitino/issues/13206)
  - **Service discovery**: Support an advertised URI for Iceberg REST service discovery. [#13098](https://github.com/apache/gravitino/issues/13098)
  - **Connection testing**: Allow catalog users to test existing catalog connections with stored configuration. [#13085](https://github.com/apache/gravitino/issues/13085)
  - **Health reporting**: Report unhealthy status after observed out-of-memory errors. [#13066](https://github.com/apache/gravitino/issues/13066)
  - **Job status**: Use `entityStore.update()` for job status transitions. [#12669](https://github.com/apache/gravitino/issues/12669)
  - **Ownership**: Support group owners in `batchGetOwner`. [#12532](https://github.com/apache/gravitino/issues/12532)
  - **Policies**: Support FUNCTION and VIEW metadata object policies. [#12501](https://github.com/apache/gravitino/issues/12501)
  - **Catalogs**: Support connection tests with proposed changes. [#12794](https://github.com/apache/gravitino/issues/12794)
  - **Catalogs**: Support testing existing catalog connections. [#12552](https://github.com/apache/gravitino/issues/12552)
  - **Indexes**: Add a `properties` field to `TableChange.AddIndex` for custom index parameters. [#11946](https://github.com/apache/gravitino/issues/11946)
  - **Security**: Harden JDBC unsafe-parameter detection against `connectionProperties` smuggling. [#12024](https://github.com/apache/gravitino/issues/12024)
